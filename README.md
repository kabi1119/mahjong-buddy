## 好牌，從齊人開枱開始

**v1.0.0rc5 · 測試版**。為真實、實體麻雀牌局而設：平時專心打牌，食糊（胡牌）後才重建手牌、核對計分，再明確確認四人結算。毋須逐次輸入摸牌或棄牌。

深綠牌桌、奶油色牌面與原創一索小鳥，配合淺色／深色及跟隨系統外觀。手機可自然捲動，桌面維持約 590px 的置中單欄。

## 由開局到結算

1. **齊人開枱**：設定四位牌友及頭像，從桌中央設定家規，再揀莊、擲骰、按牌牆圖配牌。日本模式須先輸入實際揭開的首張寶牌指示牌。
2. **平時只記重要動作**：點牌友記錄上牌（吃牌）、碰、槓及日本立直。Smart Chi 根據上家棄牌列出圖像順子；加槓只升級同局有效碰，保留原牌組 ID。
3. **選贏家與方式**：由贏家動作選單進入。港式選自摸／出銃（放槍）；日本選自摸／榮和。棄牌和牌須指定來源玩家。
4. **重建並核對**：自動帶入目前實體局的已記錄牌組；上方已選牌可點選移除，下方按萬、筒、索、番子或港式花牌加入。槓佔三個邏輯位、四張實體牌；普通手牌共十四個邏輯位，花牌另計。欠漏牌組可補錄／更正。
5. **指定和牌張並鎖定**：最後選的手牌自動成為金框「和牌張」，亦可直接改選。核對副露、情境及實體和牌資格後，先看完整確認視窗，再按「確認並鎖定」。鎖定後不能普通返回改牌，但此時仍未付款。
6. **核對結果再結算**：查看番／役、飜符、指示牌、付款及四位玩家的變動，明確確認後才寫入結算並封存本局。動畫只呈現結果，重播不會再次支付。下一手使用全新實體局 ID。

港式牌型有排除與優先次序：例如小三元／大三元已含相應三元刻番，小四喜不再加其包含的混一色；例牌按選定上限處理。七花即食為兩番加自摸一番，不需要普通十四張牌。花糊與首巡、槓補或牌尾情境複合的家規尚未支援，會阻止結算。

**寶牌不是役。** 日本首張及槓寶牌指示牌存於本局，所有玩家共用；未翻開、待確認、稍後補錄均有明確狀態。只有已揭有效位置參與計分。裏寶牌只對已確認立直的贏家輸入，數量須對應有效位置。槓後由王牌嶺上牌補一張，指示牌不會被摸走。

累計役滿有三種政策：預設 13 飜以上只算單倍（26 飜亦不加倍）、三倍滿封頂，或自選無封頂家規，按每滿 13 飜增加一倍（13–25／26–38／39–51／52–64 飜為一／二／三／四倍，繼續類推）。無封頂並非通用日麻規則；畫面顯示實際飜數，付款及效果依相應倍數處理。複合／多倍役滿是多個真正役滿或已啟用的雙倍變體，兩者分開處理。這是 **Mahjong Buddy 休閒家規**，並非完整 WRC 賽制。

## 每一局，有跡可循

- **輪莊與冧莊（連莊）**：港式莊家贏牌續莊，否則過莊；日本莊家贏牌續莊並加一本場，閒家贏牌過莊並清本場。
- **流局照常使用**：港式可選流局續莊／過莊；日本四人逐一確認聽牌／未聽牌，按總額 3,000 分攤，兩者均加一本場，供託延續。
- **四槓散了**：休閒家規預設啟用，至少兩位玩家合共四個完成槓才提示；第四槓補嶺上牌、出牌且無人和牌後才可確認。單人四槓可繼續向四槓子和牌，第五槓禁止。WRC 2025 不承認途中流局，因此本設定並非 WRC 預設。
- **紀錄與撤銷**：流局可按限制撤回；已正式支付的和牌必須填寫原因並明確審計撤銷，恢復之前點數、供託、莊家與局數。下一局已有動作或草稿時會阻止撤銷。原鎖定快照保留。
- **安全重設**：行牌「重設開局（保留牌友）」與開局前「清除牌友並重設」各有確認。兩者保留規則偏好、歷史與草稿；取消或 Escape 不重設。

## 支援範圍，講清楚

程式可驗證輸入牌型、張數、已知實體副本、役／番及已支援付款規則；**沒有逐次棄牌資料，不能自行驗證振聽、過水、完整宣告時機或實體牌是否確實存在**。這些資格和特殊情境須由牌友明確核對，不會預設獲得一發、海底、首巡役等。

目前只結算單一贏家及普通付款。多家榮和、包牌／責任支付、分攤出銃、額外地方役、Renhou、人為罰則、終局順位／Uma、飛人規則及小數付款未實作。已知可能涉及責任支付的公開大三元、大四喜、第四大明槓等組合會保守阻止，讓實體牌桌處理。未知資料或不支援的情況會顯示原因，不能鎖定或正式結算。

## 牌友資料，留在你的瀏覽器

**毋須登入，沒有分析追蹤、帳戶或雲端同步。** 玩家、偏好、動作、草稿、指示牌、鎖定手牌、點數與歷史留在本機 IndexedDB。Cloudflare 只提供前端檔案，仍會收到正常網頁請求。

舊資料庫名稱及識別碼保留。舊版未扣點的立直局須明確核對實際點數和供託；舊私人指示牌保留供核對，不會自動猜作全桌寶牌。未知未來版本或讀取失敗不會以預設值覆寫。

不同裝置、瀏覽器與網址來源不會共享資料；清除網站資料可移除紀錄。目前沒有雲端備份、匯出／匯入或完整離線 PWA 快取。本機儲存錯誤會在畫面提示；鎖定／正式付款需儲存已就緒。
